# Entregables — Aula Virtual, Semana 12

Este repositorio contiene los entregables solicitados en la tarea:

1. **Proyecto instrumentado:** código fuente, dependencias declaradas, configuración de las herramientas y scripts npm.
2. **Pruebas automatizadas:** suites unitarias, de integración API y E2E, junto con sus resultados.
3. **Informes de calidad:** cobertura, ESLint, k6 y dashboard UniReport.
4. **Informe técnico:** resultados, análisis, mejoras y conclusiones.

La carpeta [`proyecto-aulavirtual`](./proyecto-aulavirtual) permite revisar cada archivo. El ZIP [`Entregables_AulaVirtual_Semana12.zip`](./Entregables_AulaVirtual_Semana12.zip) contiene la carpeta del proyecto empaquetada, sin `node_modules`; instala dependencias con `npm ci`.

Consulta [`proyecto-aulavirtual/README.md`](./proyecto-aulavirtual/README.md) para ejecutar el flujo de calidad con `npm run quality`.
